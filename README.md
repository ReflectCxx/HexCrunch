# HexCrunch

**Swap colors. Complete rings. Unleash cascading crunches!**

HexCrunch is a casual hexagonal puzzle game where simple moves can set off satisfying chain reactions.

Navigate a colorful, rotating hexagonal board, swap neighboring colors, and bring matching colors together to complete entire rings. Watch them pop as the board crunches inward, potentially triggering even more cascading clears!

Designed for effortless one-thumb play, HexCrunch brings a playful twist to color-matching puzzles — easy to pick up, with plenty of room for clever moves.
